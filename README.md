# QAISARA DIGITAL STORE — Frontend

Etalase produk digital + dashboard admin. Frontend statis (HTML/CSS/JS) untuk **GitHub Pages**;
backend berupa **Google Apps Script** (REST API JSON) dengan database Google Sheets & Google Drive.

```
index.html        ← halaman utama (harus di root repo)
css/style.css     ← seluruh styling
js/config.js      ← ISI GAS_URL di sini sebelum push
js/api.js         ← klien fetch ke GAS
js/app.js         ← logika etalase & dashboard admin
```

Backend (`Kode.gs`) **tidak** disimpan di repo ini — tempel di editor Apps Script.
Panduan lengkap: lihat `PANDUAN-INSTALASI.md`.
